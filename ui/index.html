What this does and does not enforce

    
    
      
  • It enforces payment before first delivery. Without a valid envelope
        there is no key, and the ciphertext is just noise. Each portrait has its own key, so
        ordering one hands over one.
    • 
      
  • It does not stop redistribution. A subscriber holds the content key
        and the decrypted pixels, and can publish either. There is no cryptographic answer to
        that — only DRM, which this is not. Netflix has the same property and a screen recorder.
    • 
      
  • Expiry gates future deliveries, not past ones. A key already handed
        over cannot be taken back by a date.
    • 
      
  • The gatekeeper is needed to sell, never to serve. Stop it and every
        existing subscriber keeps working; the entitlement is already replicated and the
        ciphertext is already here.
    • 
      
  • esmeralda is a faucet testnet. Test XTR is free to obtain, so the
        price is a demonstration of payment plumbing, not an economic barrier.
